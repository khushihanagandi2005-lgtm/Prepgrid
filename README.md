# PrepGrid – Placement Preparation Platform

## About the Project
PrepGrid is a web application that helps students prepare for campus placements. It provides coding practice, quizzes, mock interviews, and progress tracking in one platform.

## Features
- Student registration and login
- Student dashboard
- Coding practice
- Bookmark questions
- Mock interviews
- Aptitude and technical quizzes
- Track quiz results and progress
- Admin panel to manage questions and users

## Technologies Used
- HTML, CSS, JavaScript
- Node.js
- Express.js
- JWT Authentication
- JSON / SQLite database (depending on backend configuration)

## Installation

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies:
   "npm install"


4. Create a `.env` file and configure the required environment variables.
5. Start the application:
"npm run dev" or 
"npm start"


6. Open your browser and visit:

http://localhost:5000
